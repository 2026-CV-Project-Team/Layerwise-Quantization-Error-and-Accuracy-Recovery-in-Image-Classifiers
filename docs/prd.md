# ImageNet 층별 양자화 실험 계획서

## 1. 목적과 범위

ImageNet-1K에서 ResNet-18과 DeiT-Tiny의 층별 양자화 오차, 최종 분류 점수 오차, Top-1 정확도, 추정 모델 저장 용량을 비교한다. **양자화 오차가 큰 층을 복원하면 정확도도 많이 회복되는가**를 확인하고, 같은 저장 용량에서 정확도를 더 잘 유지하는 층별 비트 배정을 찾는다.

두 모델 모두 사전학습 가중치를 사용해 재학습이나 미세조정 없이 학습 후 양자화(PTQ)를 적용한다. 기존 [실험 규격](experiment_spec.md)의 학습 방식 미정 항목에 대해 이번 실험에서는 사전학습 모델 사용을 확정한다.

| 모델 | 사전학습 기준 | 양자화 단위와 순서 |
| --- | --- | --- |
| ResNet-18 | torchvision IMAGENET1K_V1 | Stem → BasicBlock 8개 → FC, 총 10개 |
| DeiT-Tiny | timm deit_tiny_patch16_224 | Patch Embedding → Transformer Block 12개 → Head, 총 14개 |

- **W**는 단위 안의 Conv·Linear 가중치이고, **A**는 해당 단위의 출력 활성값이다. ResNet의 downsample Conv는 해당 블록에 포함한다. 입력 이미지, 편향, 블록 내부의 중간 활성값은 FP32로 처리한다.
- 최종 분류기 FC·Head도 양자화 단위에 포함한다. W는 분류기 가중치에 적용한다. **분류기 출력 점수(로짓)는 기본적으로 FP32로 유지**하고, 로짓까지 양자화한 결과는 2.1절 동일 비트 조건에서만 별도로 기록한다.
  - 근거(11-18 측정, rank 5,000장, 로짓만 양자화하고 나머지는 FP32): 로짓 4비트에서 최고 점수가 둘 이상 같은 이미지가 ResNet-18 35.8%, DeiT-Tiny 18.6%였다. 이때 Top-1은 동률 처리 규칙(앞 번호 클래스 선택)에 따라 정해지고, 정확도는 ResNet-18 70.42 → 64.60%, DeiT-Tiny 73.36 → 72.00%로 떨어졌다. ResNet-18 로짓 6비트는 70.64%로 FP32보다 높게 나왔는데, 이것도 동률 처리 때문이다.
  - 로짓을 양자화하면 분류기 단위의 복원 이득과 단독 하락에 동률 처리 효과가 섞여, 층의 민감도를 비교하려는 목적과 맞지 않는다. 6-Conv(Head FP32)와 기존 ImageNet 결과와도 같은 조건이 된다.
- ResNet은 Conv와 BatchNorm을 결합한 FP32 모델을 기준으로 한다. W는 출력 채널별 대칭 min-max, A는 텐서별 비대칭 min-max로 설정한다. 체크포인트, 전처리, 데이터 목록과 실행 환경을 기록한다.

### 데이터 분할과 사용 원칙

| 분할 | 규모 | 용도 |
| --- | ---: | --- |
| 보정용 train | 2,048장 | 모델별 FP32 순전파로 활성값 범위를 한 번 계산해 모든 조합에 재사용한다. |
| rank | 5,000장 | 층별 오차·복원 효과의 순위 산정, 4·8비트 조합 평가, Pareto 후보 선정에 사용한다. |
| test | 10,000장 | FP32, 2.1절의 전 단위 동일 비트 조건, rank에서 확정한 Pareto 후보를 최종 평가한다. |

**보정 세트 반복**: 사전학습 모델은 고정이라 실행마다 달라지는 것은 보정 이미지뿐이다. 기존 반복 측정(seed 0·1, PR #21)에서 활성값 4비트 정확도가 보정 세트에 따라 3~4%p 달라졌다(ResNet-18 W4A4 17.13 / 14.00%). 그래서 2.1절 동일 비트 조건과 3절 복원 실험은 보정 세트 seed 0~2(서로 겹치지 않는 train 이미지 2,048장씩)로 반복하고 평균 ± 표준편차로 보고한다. 2.2절 4·8비트 조합은 비용 때문에 seed 0으로만 평가하고, test에서 확정 후보만 seed 0~2로 다시 평가한다.

rank와 test는 서로 겹치지 않는 ImageNet 검증 이미지로 고정한다. 층 순위, 비트 배정, Pareto 후보는 **rank 5,000장**으로 확정하고 후보 ID를 저장한 뒤 test를 실행한다. test 결과는 확정된 후보의 최종 성능을 보고하는 데 사용한다.

## 2. 양자화 실험

### 2.1 동일 비트 및 단일 층 비교

이전 ImageNet 실험에서 W8A8의 Top-1 정확도는 FP32 대비 ResNet-18에서 0.25%p, DeiT-Tiny에서 0.43%p 낮았다. 이를 근거로 양자화 비트를 **{4, 5, 6, 8}**로 좁힌다. 로짓 FP32 유지는 앞선 결과와 같은 조건이므로 기존 결과와 직접 비교할 수 있다. 전 단위 동일 비트 조건에서는 로짓까지 양자화한 결과도 함께 기록하고, 최고 점수 동률 비율을 같이 남긴다. [기존 ImageNet 조건별 결과](https://github.com/2026-CV-Project-Team/Layerwise-Quantization-Error-and-Accuracy-Recovery-in-Image-Classifiers/blob/e2ef69a/results/imagenet/summary/conditions.csv)

모델마다 W32A32를 FP32 기준으로 한 번 실행한다. 각 b ∈ {4, 5, 6, 8}에 대해 아래 조건을 전 단위에 적용한 경우와, 나머지 단위를 FP32로 두고 각 단위에 하나씩 적용한 경우를 평가한다. 단일 층 실험으로 W와 A의 영향을 분리하고, 전체 양자화 조건은 비트별 기준값 및 복원 실험의 출발점으로 사용한다.

| 실험 모드 | 조건 |
| --- | --- |
| W·A 동시 양자화 | WbAb |
| W만 양자화 | WbA32 |
| A만 양자화 | W32Ab |

### 2.2 단위별 4·8비트 전수 비교

6-Conv 실험과 같은 방식으로 각 단위에 **W4A4 또는 W8A8**을 독립적으로 배정한다. 8비트 단위는 어느 위치에나 올 수 있으며, 전체 4비트와 전체 8비트도 후보에 포함한다. 전체 4비트·8비트 끝점은 2.1절의 동일 조건 실행 결과를 재사용한다. 5·6비트 및 W만·A만 양자화의 비교는 2.1절에서 수행한다.

| 모델 | 단위 수 N | 배정 수 2^N | rank 평가 규모 | 예상 시간 (M4 MPS, FP32 추론 속도 기준 하한) |
| --- | ---: | ---: | ---: | ---: |
| ResNet-18 | 10 | 1,024 | 약 512만 장 추론 | 약 3.3시간 |
| DeiT-Tiny | 14 | 16,384 | 약 8,192만 장 추론 | 약 172시간 |

DeiT-Tiny 전수는 노트북 한 대로 실행하기 어렵다(11-17 반복 측정 중 발열로 비상 절전 발생). 그래서 범위를 다음처럼 나눈다.

| 모델 | 평가 범위 | 조건 수 | 예상 시간 |
| --- | --- | ---: | ---: |
| ResNet-18 | 2^10 전수 | 1,024 | 약 3.3시간 |
| DeiT-Tiny | 8비트 단위 수 n8 ≤ 2 또는 n8 ≥ 12 전수 | 212 | 약 2.2시간 |
| DeiT-Tiny | 탐욕 경로: 전체 4비트에서 시작해, 매 단계 저장 바이트 증가 대비 rank 정확도 증가가 가장 큰 단위 하나를 8비트로 올림 | 최대 105 | 약 1.1시간 |

- 탐욕 경로는 각 단계에서 남은 4비트 단위를 모두 시험하므로 단계 j에서 N−j개를 평가한다(합 N(N+1)/2 이하).
- 탐욕 경로가 전수 Pareto를 얼마나 잘 따라가는지는 **ResNet-18에서 전수 결과와 비교해 검증**한다. 같은 저장 용량에서 탐욕 경로와 전수 Pareto의 정확도 차이를 보고한다.
- DeiT-Tiny 결과는 전수가 아니라는 점과 평가 범위(212 + 탐욕 경로)를 명시해 보고한다.

먼저 두 모델의 대표 조합으로 조건당 시간과 결과 저장량을 측정한다. 이후 조합을 일정한 순서로 나눠 실행하고, 조합 ID별 상태를 기록해 중단한 지점부터 재개한다. 결과를 공유할 때는 모델별 완료 조건 수와 명목상 조합 수를 함께 보고한다. 전체 평가가 끝나기 전의 Pareto 후보는 rank에서만 잠정 집계한다.

### 2.3 저장 용량과 정확도의 Pareto 비교

모델별로 **추정 모델 저장 바이트는 낮을수록, rank Top-1 정확도는 높을수록** 유리한 것으로 본다. 다른 조합이 저장 용량 이하이면서 정확도 이상이고, 두 지표 중 하나 이상에서 더 좋으면 해당 조합은 제외한다. 남은 비지배 조합을 Pareto 후보로 저장한다.

같은 저장 용량과 정확도를 가진 배정은 비트 벡터가 숫자 순서로 가장 앞선 하나를 대표로 삼고 동률 조합 ID를 기록한다. rank에서 후보와 대표 배정을 확정한 뒤 test Top-1과 FP32 대비 정확도 변화를 평가한다. 결과 그래프에는 rank에서 정한 Pareto 후보와 그 후보의 test 정확도를 표시한다.

## 3. 단일 층 복원 실험

모든 단위를 같은 비트로 양자화한 W4A4·W5A5·W6A6·W8A8에서, **한 단위의 W와 A만 FP32로 복원**한다. 다른 N−1개 단위는 시작 비트를 유지한다. 비트 조건마다 ResNet-18에서 10개, DeiT-Tiny에서 14개의 복원 조건을 비교한다.

1. 전 단위 양자화 상태에서 각 단위의 출력 NMSE를 측정해 **층 오차 순위**를 정한다.
2. 한 단위씩 복원하고 전 단위 양자화 기준보다 얼마나 개선되는지 측정한다. **복원 이득(%p)**은 복원 후 Top-1에서 전 단위 양자화 Top-1을 뺀 값이다. **최종 출력 NMSE 감소량**은 전 단위 양자화 NMSE에서 복원 후 NMSE를 뺀 값이다.
   보조로 **최종 출력 KL 감소량**(FP32 softmax 대비 KL, 복원 전 − 복원 후)을 함께 기록한다. 기존 측정에서 KL 감소량과 복원 이득의 순위 상관은 ResNet-18 W4A4 0.93, DeiT-Tiny W5A5 0.99였고, 정답 라벨 없이 계산된다. W6A6·W8A8처럼 정확도가 거의 포화돼 복원 이득이 잡음 수준(±1%p 이하)인 조건에서는 이 값으로 순위를 보완한다.
3. 각 비트에서 층 오차 순위와 복원 이득 순위를 비교해 어떤 층이 상위에 드는지 보고한다. Spearman 순위 상관과 1위 일치 여부를 함께 기록한다. 동률을 표시하고, 값이 전부 같아 순위 상관을 계산할 수 있는 차이가 없으면 해당 지표를 산출 불가로 표시한다.

이 순위 비교에는 **rank 5,000장**을 사용한다. 단일 층을 FP32 기준에서 양자화하는 실험(2.1절)과 전 단위 양자화 상태에서 단일 층을 복원하는 실험(3절)은 각각의 기준에 맞춰 결과를 기록한다.

## 4. 측정 지표와 저장 용량 계산

| 지표 | 측정 방법 |
| --- | --- |
| 층별 출력 오차 | 각 단위 출력이 FP32 모델의 같은 위치 출력과 얼마나 다른지 NMSE로 계산한다. 양자화하지 않은 단위도 기록해 앞 단위에서 전달된 오차를 볼 수 있게 한다. |
| 최종 출력층 오차 | 최종 분류기의 전체 클래스 점수(로짓)를 FP32 로짓과 비교해 NMSE를 계산한다. 분류기 A를 양자화한 경우 양자화 이후 로짓을 사용한다. |
| 품질·정확도 | ImageNet의 실제 라벨을 기준으로 Top-1 정확도(%)와 FP32 대비 변화(%p)를 기록한다. |

NMSE는 이미지마다 출력 차이의 제곱합을 FP32 기준 출력의 제곱합으로 나눈 뒤 해당 분할 전체에서 평균한다. 분모의 하한은 1e-12로 둔다. 조합별 결과에 rank와 test를 각각 표기한다.

### 모델 저장 용량 추정

Mac의 MPS에서 **모의 양자화(fake quantization)**로 오차와 정확도를 평가한다. 이 방식에서는 저비트 값의 반올림을 재현한 텐서를 FP32로 저장하므로, Pareto 비교에는 아래 규칙으로 계산한 **추정 모델 저장 용량**을 사용한다. [PyTorch FakeQuantize 문서](https://docs.pytorch.org/docs/2.15/generated/torch.ao.quantization.fake_quantize.FakeQuantize.html)

- 파라미터 용량은 텐서마다 원소 수 × 저장 비트를 계산해 바이트로 올림한 뒤 합산한다. 양자화할 가중치는 배정한 W 비트 수를, 나머지 파라미터와 편향은 32비트를 적용한다. 공유 파라미터는 한 번만 센다.
- 메타데이터 용량은 스케일, 영점(zero-point), 비트 설정 등 모델과 양자화에 필요한 항목의 개수와 자료형에 따라 계산한다. 가중치·활성값 양자화 메타데이터와 공통 모델 메타데이터를 구분해 기록한다. 기본 형식(잠정)은 다음과 같다.
  - W: 출력 채널마다 FP32 스케일 1개(4바이트). 대칭 양자화라 영점은 저장하지 않는다.
  - A: 단위마다 FP32 스케일 1개와 정수 영점 1개(4 + 4바이트).
  - 비트 설정: 단위마다 W·A 비트 각 1바이트.
- **추정 모델 저장 바이트 = 파라미터 바이트 + 메타데이터 바이트**로 계산하고, 두 항목을 결과표에 함께 표시한다. A 비트 수는 가중치 저장 용량에 곱하지 않으며, A의 보정값은 메타데이터에 넣는다.
- 실제 패킹 모델의 상주 메모리와 활성값·임시 버퍼를 포함한 **추론 피크 메모리 실측은 확장 과제**로 둔다.

## 5. 결과 저장과 정렬

모델과 실험 종류별로 결과를 저장한다. 단일 층 양자화와 복원은 양자화된 단위 수 k로 구분한다. 4·8비트 전수 실험에서는 모든 단위가 양자화되므로 **8비트로 배정한 단위 수**로 조합을 묶는다.

~~~text
results/imagenet_quantization/<model>/
  baseline/
  uniform/<wa|w_only|a_only>/
  single/<wa|w_only|a_only>/k=01/
  restore/k=<N-1>/
  mixed_4_8/n8=<8비트 단위 수>/
  pareto/
~~~

각 그룹 안에서 순전파 순서의 단위 번호와 비트 벡터를 숫자 오름차순으로 정렬한다. 결과에는 모델·체크포인트, 분할, 양자화 모드, 단위별 W/A 비트, 층별·최종 NMSE, Top-1과 정확도 변화, 파라미터·메타데이터 추정 바이트, 조합 ID와 실행 상태를 기록한다. 복원 결과에는 층별 복원 이득을, Pareto 결과에는 rank에서 확정한 후보 ID와 해당 후보의 test 평가를 함께 저장한다.
