# ImageNet 층별 양자화 실험 계획서

## 1. 목적과 범위

ImageNet-1K에서 ResNet-18과 DeiT-Tiny를 대상으로, 어느 층을 몇 비트로 양자화할 때 층별 출력 오차, 최종 분류 점수 오차, 분류 정확도, 실제 추론 메모리가 어떻게 달라지는지 측정한다. 결과를 바탕으로 정확도와 메모리 사용량을 함께 비교한다.

두 모델은 **사전학습 가중치로 불러와 재학습 및 미세조정 없이 학습 후 양자화(PTQ)** 한다. 기존 [실험 규격](experiment_spec.md)의 학습 방식 미정 항목에 대해, 이번 실험에서는 사전학습 모델 사용을 확정한다.

| 모델 | 사전학습 기준 | 양자화 단위와 순서 |
| --- | --- | --- |
| ResNet-18 | torchvision IMAGENET1K_V1 | Stem → BasicBlock 8개 → FC, 총 10개 |
| DeiT-Tiny | timm deit_tiny_patch16_224 | Patch Embedding → Transformer Block 12개 → Head, 총 14개 |

- **W**는 단위 안의 대상 Conv·Linear 가중치, **A**는 해당 단위가 다음 단계에 넘기는 출력 활성값이다. ResNet의 downsample Conv는 해당 블록에 포함한다. 입력 이미지, 편향, 블록 내부의 중간 활성값은 FP32로 처리한다.
- 최종 분류기 FC·Head도 조합에 포함한다. W 조건은 분류기 가중치에, A 조건은 분류기 출력 점수(로짓)에 적용한다. 기존 ImageNet 실험 코드에서는 분류기 로짓 양자화가 기본적으로 꺼져 있으므로, 이번 실험에서는 이 설정을 명시적으로 켜고 결과에 기록한다.
- ResNet은 Conv와 BatchNorm을 결합한 FP32 모델을 기준으로 한다. 체크포인트와 전처리를 고정하고, 기존 분할을 따라 보정용 이미지 2,048장과 별도의 최종 평가 이미지 10,000장을 사용한다. 활성값 보정 범위는 모델별 FP32 순전파에서 한 번 구해 조합 간 재사용한다.
- 기존 규격을 따라 W는 출력 채널별 대칭 min-max, A는 텐서별 비대칭 min-max를 사용한다. 실행 결과에는 체크포인트 식별자, 데이터 분할과 보정값, 양자화 규칙 및 실행 환경을 기록한다.

## 2. 양자화 실험

### 2.1 전 단위 동일 비트 비교

각 모델의 모든 단위에 W와 A의 비트를 동일하게 지정한다. **W4A4, W5A5, …, W31A31, W32A32의 29개 조건**을 평가한다. 32는 32비트 정수 양자화가 아니라 FP32 유지이고, W32A32는 두 모델 각각의 기준 추론 결과다.

W만 낮춘 W4A32~W31A32와 A만 낮춘 W32A4~W32A31도 각 모델에서 전 단위에 적용한다. 전 단위 동일 비트 조건은 아래 전수 조합에도 포함되므로 한 번 실행해 두 비교에 사용한다.

### 2.2 양자화 단위와 비트 조합 전수 비교

모델에 양자화 단위가 N개 있으면 양자화할 단위 수 k를 1부터 N까지 늘린다. 각 k에서 크기가 k인 **모든 부분집합**을 실행한다. 예를 들어 k=2에는 1·2번뿐 아니라 1·4번, 2·5번처럼 떨어진 단위도 포함한다. 선택하지 않은 단위에는 FP32를 적용한다.

같은 부분집합에서도 선택한 단위마다 **4~31비트 중 하나를 독립적으로 지정**해 가능한 모든 비트 배정을 평가한다. 예를 들어 1·4번을 선택했을 때, 1번 4비트·4번 8비트와 1번 8비트·4번 4비트는 서로 다른 조건이다. 이 규칙을 다음 세 실험에 각각 적용한다.

| 실험 | 선택 단위의 비트 배정 |
| --- | --- |
| W·A 동시 양자화 | 단위별로 하나의 비트 수 b를 정해 WbAb를 적용한다. 단위끼리는 서로 다른 b를 사용할 수 있다. |
| W만 양자화 | 단위마다 WbA32를 적용한다. |
| A만 양자화 | 단위마다 W32Ab를 적용한다. |

k=0은 공통 FP32 기준값으로 모델마다 한 번 수행한다. k별 조건 수는 모드당 C(N, k) × 28^k이고, 양자화 조건 총수는 모드당 29^N − 1이다.

| 모델 | k=1 | k=2 | k=3 | 전체 양자화 조건 수, 모드당 |
| --- | ---: | ---: | ---: | ---: |
| ResNet-18 | 280 | 35,280 | 2,634,240 | 420,707,233,300,200 |
| DeiT-Tiny | 392 | 71,344 | 7,990,528 | 297,558,232,675,799,463,480 |

전수 범위는 위 규칙으로 정의한다. 실제 실행은 조합을 순서대로 생성하고, 모델·모드·k·조합 범위별로 나눠 재개할 수 있도록 한다. 먼저 전 단위 동일 비트와 일부 조합을 실행해 조건당 평가 시간과 결과 용량을 측정하고, 이를 바탕으로 전수 실행 규모를 산정한다. 조건별 상태를 완료·실패·미실행으로 집계하며, 일부 실행 결과에는 실제 평가한 범위와 전체 대비 완료율을 함께 표시한다.

### 2.3 오차와 정확도

모든 조건에서 같은 평가 이미지와 같은 모델의 FP32 기준 출력을 사용한다.

| 지표 | 측정 방법 |
| --- | --- |
| 각 층의 출력 오차 | 각 단위의 출력 활성값을 FP32 모델의 같은 위치 출력과 비교해 NMSE를 계산한다. 양자화 대상에 포함된 단위와 나머지 단위 모두 기록해 앞 단위의 오차가 전달되는 영향도 확인한다. |
| 최종 출력층 오차 | 최종 분류기의 ImageNet 클래스 점수 전체를 FP32 로짓과 비교해 NMSE를 계산한다. FC·Head의 A까지 양자화한 조건에서는 양자화 이후의 로짓을 사용한다. |
| 품질·정확도 | 실제 라벨 기준 ImageNet Top-1 정확도(%)와 FP32 기준 대비 정확도 변화(%p)를 기록한다. 변화량은 해당 조건 정확도에서 FP32 정확도를 뺀 값이다. |

NMSE는 이미지마다 출력 차이의 제곱합을 FP32 기준 출력의 제곱합으로 나눈 뒤, 평가 이미지 전체에서 평균한다. 분모에는 기존 코드와 같은 하한값 1e-12를 적용한다. 마지막 단위의 출력과 최종 로짓이 같으면 같은 계산값을 두 지표에서 참조한다.

### 2.4 실제 메모리 측정

**각 조건에 실제로 로드된 파라미터와 메타데이터가 점유한 바이트를 측정한다.** 메모리 항목을 구분해 어떤 변화가 가중치, 활성값, 부가 데이터에서 비롯됐는지 확인한다.

| 항목 | 기록할 값 |
| --- | --- |
| 파라미터 상주 메모리 | 로드 후 추론에 사용하는 저비트 가중치와 FP32 파라미터가 실제로 할당받은 저장소 크기. 패킹으로 생긴 패딩을 포함하고, 공유 저장소는 한 번만 센다. FP32 복사본이나 상주 캐시가 있으면 용량을 따로 기록한다. |
| 모델·양자화 메타데이터 | 스케일, 영점(zero-point), 비트 설정, 패킹 정보를 비롯하여 모델 그래프·텐서 설명 등 런타임에서 유지하는 부가 데이터의 바이트. 모델과 양자화 메타데이터의 소계를 각각 저장한다. |
| 추론 피크 메모리 | 모델 로드 직후 상주량과 추론 중 최대 할당량. 활성값, 양자화·역양자화 임시 버퍼, 연산 작업 공간을 추적한다. 예약 메모리를 제공하는 환경에서는 할당량과 예약량을 각각 기록한다. |

- 같은 장치, 백엔드, 배치 크기, 입력 크기에서 FP32와 각 조건을 비교한다. 호스트 메모리와 가속기 메모리를 구분하며, 측정 도구와 집계 범위를 함께 기록한다. 가속기에서는 동기화한 뒤 로드 직후 값을 읽고, 준비 실행 후 피크 통계를 초기화해 추론을 측정한다.
- 기존 fake quantization은 반올림 오차를 재현하면서 가중치를 FP32 텐서에 저장한다. 용량 절감 평가는 저비트 값을 실제로 패킹해 로드하는 실행 경로에서 한다. 사용한 저장 형식과 실제 연산 경로를 기록한다. 특정 비트의 네이티브 연산을 지원하지 않아 패킹 후 복호화해 계산할 경우, 그 복호화 버퍼도 추론 피크에 포함한다.
- 파라미터 수 × 비트 수로 구한 이론 용량은 비교용으로 기록한다. 메타데이터를 분리할 수 없거나 실제 저비트 저장 경로를 아직 측정하지 못한 항목은 미측정으로 표시하고 측정 범위와 이유를 남긴다. 실측 용량이 필요한 조건은 해당 값이 확보돼야 완료로 집계한다.

측정 도구 참고는 [PyTorch fake quantization](https://docs.pytorch.org/docs/stable/generated/torch.ao.quantization.fake_quantize.FakeQuantize.html), [CUDA 메모리 할당과 예약](https://docs.pytorch.org/docs/stable/notes/cuda.html#cuda-memory-management), [CUDA 메모리 측정 범위](https://docs.pytorch.org/docs/stable/torch_cuda_memory.html)를 따른다.

### 2.5 결과 저장과 정렬

모델과 실험 모드 아래에 **양자화한 단위 수 k별로 폴더**를 만들고, 같은 k 안에서 단위 조합별 결과를 모은다. 조건 수가 많은 조합은 같은 열 구조를 가진 여러 결과 파일로 나눠 저장한다.

~~~text
results/imagenet_quantization/
  <model>/
    baseline/
    <wa|w_only|a_only>/
      k=01/
        units=01/
      k=02/
        units=01-02/
        units=01-04/
      k=03/
        units=01-02-03/
      ...
~~~

1. 단위 번호는 모델의 순전파 순서에 따라 1부터 부여한다. 폴더의 k는 오름차순으로, 같은 k 안의 단위 조합은 오름차순 단위 번호 튜플로 정렬한다.
2. 같은 단위 조합 안에서는 해당 순서의 비트 튜플을 숫자 오름차순으로 정렬한다. 예를 들어 1·4번 조합의 (4, 8)은 (8, 4) 앞에 놓는다. 모델·모드·단위 튜플·비트 튜플을 조건 식별자로 사용한다.
3. 조건별 결과에는 단위별 W/A 설정, 층별 NMSE, 최종 출력 NMSE, Top-1 및 FP32 대비 변화, 메모리 항목별 실측 바이트, 장치와 실행 환경, 실행 상태를 저장한다. 전체 비교표에서는 정확도와 실제 파라미터·메타데이터·추론 피크 메모리를 함께 조회할 수 있게 한다.

## 3. 복원 실험

이번 계획에서는 **복원 실험을 진행하지 않는다.** 모든 조합은 FP32 기준 모델에서 출발해 해당 조건에 지정한 단위만 양자화하여 평가한다.

## 4. 검토 의견 (11-17, 정채호준)

계획 확정 전 논의용 제안. 1~3절 원문은 그대로 두고 제안만 덧붙임. 시간 수치는 M4 맥(MPS) 기준 추정치.

### 4.1 전수 조합 규모

- 조건 수: 모드당 29^N − 1 (ResNet-18 약 4.2×10¹⁴, DeiT-Tiny 약 3.0×10²⁰), 모드 3개
- 평가 1회(test 1만 장) 소요: ResNet-18 약 23초, DeiT-Tiny 약 76초
  - FP32 추론 속도 431장/초, 132장/초 기준 하한. fake quant와 층별 NMSE 계산 비용 제외
- 4~31비트 k ≤ 2만으로도 모드당 ResNet-18 35,560조건 약 227시간, DeiT-Tiny 71,736조건 약 1,514시간
- 9비트 이상의 효용 낮음: 기존 측정에서 W8A8의 FP32 대비 정확도 차이 ResNet-18 −0.25%p, DeiT-Tiny −0.43%p (test)
- 제안 A: 비트 {4, 5, 6, 8} + FP32, k ≤ 2 전수
  - 모드당 ResNet-18 760조건 약 5시간, DeiT-Tiny 1,512조건 약 32시간
- 제안 B: 6-Conv와 같은 방식. 전 단위를 4 또는 8비트로 두는 2^N 조합 + 같은 Weight Bit Cost 기준 Pareto frontier
  - ResNet-18 1,024조합 약 6.5시간
  - DeiT-Tiny 16,384조합 약 346시간 → 기존 정책 기반 선택(Early-High, Late-High, NMSE, 단독 민감도, FP32 복원 이득, Random) 유지
- 순위·조합 선택은 rank 5,000장, 최종 보고는 test 1만 장 (기존 분할 규칙, 순환 논증 방지)

### 4.2 복원 실험

- 연구 질문(층별 오차 순위와 FP32 복원 효과 순위의 일치 여부)의 핵심 측정
- 1차 발표 결론의 근거: 6-Conv Conv1 복원 +19.2%p, ResNet-18 stem 복원 +18.8%p (W4A4, rank)
- 2.2절의 k=1은 기존 단독 양자화(drop)와 동일. 복원은 k=N−1(해당 단위만 FP32)에 해당하나 k 오름차순 실행으로는 도달 불가
- 제안: 복원 실험 유지, 또는 k=N−1 동일 비트 조건을 우선 실행 대상으로 명시

### 4.3 실제 메모리 측정

- 현재 실행 경로: fake quantization, 가중치는 FP32 텐서로 저장 → 비트를 바꿔도 실측 용량 변화 없음
- 실측에 필요한 것: 4~31비트 패킹 저장과 복호화 연산 경로 신규 구현. MPS는 CUDA식 피크 통계 초기화 미지원
- 모의 양자화 결과는 정확도 결론에 한정하는 기존 연구 범위와 불일치
- 제안: 저장 용량은 Σ(파라미터 수 × 비트) + scale·zero-point 메타데이터 바이트로 계산, 추론 피크 메모리 실측은 확장 과제

### 4.4 기타
